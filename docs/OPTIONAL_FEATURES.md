# 可选能力及外部输入

| 能力 | 需要另外准备 | 缺失时 |
|---|---|---|
| 浏览器登录与UI | requirements-browser.txt、Chrome/Edge、匹配的驱动 | 登录/UI受阻，保留前置错误 |
| OAST | 自己的回调域名和interactsh等工具 | 未观察真实回调不能宣称已验证盲注/外带 |
| 组件漏洞库 | Trivy、Grype等工具及漏洞数据库 | 不能声称组件CVE已完成实测 |
| TLS及外部扫描 | 对应工具、Java或Linux环境 | 本机解析器测试仍可运行 |
| 主机与组件库存 | 本地配置的SSH、数据库、Redis信息及命令权限 | 对应项受阻，不使用旧环境口令 |
| 客户端静态分析 | 自己准备的客户端样本、解包内容或JS缓存 | 未提供样本则该部分不具备覆盖证据 |
| 重建API库存 | 原API文档、Excel或H5静态资源 | 已分发脱敏库存可使用，但不能代表新版本 |
| 桌面终端辅助 | 独立UI工程、其页面对象和本机客户端 | 不在核心安装/本地测试范围内 |

`tools_cache/`、客户端、二进制扫描器及其他项目源码不上传。应由使用者取得对应版本，按工具参数或环境变量指定路径。不自动下载未知二进制，也不复制完整第三方仓库。

已提取必需的后台登录适配器到 `adapters/browser/admin_login.py`，因此扫描主入口不需要 `sources/security-legacy`。旧库存生成器或可选终端工具仍可能需要外部文档/项目，这些输入由使用者单独准备，不影响核心模拟测试运行。

证据、原始令牌和客户结果保存在本地忽略目录。运行时输出可能包含目标数据，分享报告前仍需检查脱敏。发布清理不改变这些运行时证据的业务用途。
